# MacroMac 🦅

> Find the best meals on McMaster campus — filtered by budget, calories & protein.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Add your Anthropic API key
# Edit .env.local and replace: your_api_key_here
# Get a key at: https://console.anthropic.com

# 3. Scrape today's McMaster menu (run this daily)
npm run scrape

# 4. Start the app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## How It Works

### The Scraper
- POSTs to `macnutrition.mcmaster.ca/Nutrition/ServiceMenuReport/GetReport/{uuid}`
- One request per menu section (45 total across 8 locations)
- Also calls `FilterReport` for each section to get Halal/Veg/Vegan/GF tags
- Saves everything to `meals.json` in the project root
- Run daily — the McMaster menu changes every day

### The App
- Next.js 14 app router, fully server-side rendered
- `meals.json` is read at request time — always fresh after a scrape
- AI assistant calls Claude via your secure API key in `.env.local`
- Filters: budget, min protein, max calories, location, dietary tags
- Sorts by: value score (protein/$), most protein, cheapest, lowest calories

## Deployment (Vercel)

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel

# Set your API key in Vercel dashboard:
# Project → Settings → Environment Variables
# Key: ANTHROPIC_API_KEY
# Value: your key
```

For daily scraping on the server, set up a cron job or use Vercel Cron:
- Add to `vercel.json`:
```json
{
  "crons": [{ "path": "/api/scrape", "schedule": "0 6 * * *" }]
}
```
Then create `/app/api/scrape/route.js` that runs the scraper logic.
